1. Install the official 18.4.0.48 x64 build in the test VM. Keep an unmodified checkpoint.
2. Confirm purchase reminders appear on normal startup and tray redisplay. Test startup login as well. If the unmodified build does not show a reminder, that route is inconclusive.
3. To test backup replacement, leave a verified unmodified 18.3.0.34 executable named `ProcessLasso-Original.exe` in the installation folder.
4. Run the preview ZIP's `Start.cmd` and select **Apply patch**. The status should identify the verified older backup, and the prompt should state that it will be replaced.
5. Confirm normal startup, startup login, and tray redisplay no longer show the reproduced reminders. Check process-list updates, retained settings, and GUI restart.
6. Confirm `ProcessLasso-Original.exe` now matches the unmodified 18.4.0.48 hash in TECHNICAL.md. After successful cleanup, no `ProcessLasso-NoNag-*.tmp` files should remain.
7. Select **Restore original**. Confirm the unmodified 18.4.0.48 hash, removal of the backup, GUI restart, and return of the reproduced reminders.
